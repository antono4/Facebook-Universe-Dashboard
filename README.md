# Facebook Universe Dashboard 📊

> **Created by Antono**


![Facebook Dashboard Banner](https://images.unsplash.com/photo-1664575599736-c5197c684128?w=800)

Analytics dashboard for Facebook insights and metrics.

## ✨ Features

- 📈 Page performance metrics
- 👥 Audience insights
- 📅 Content calendar
- 🔥 Engagement tracking
- 📊 Custom reports

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/antono4/Facebook-Universe-Dashboard.git

# Open in browser
cd Facebook-Universe-Dashboard
open index.html
```
